# 记忆法训练助手（Memory Training）

一款基于快速记忆法的**记忆训练工具**，覆盖 **记数字、记单词、记古诗词、记短文** 四大练习，
手机、电脑通用，**离线可用、无依赖、无广告**，数据与逻辑全部内嵌，开箱即用。

内置记忆方法：数字编码、串联联想（锁链奇像法）、记忆宫殿、画图记忆、对应联想、抽象转具象、词根词缀等，
以及专注力训练（舒尔特方格、数数拍手、顺序记忆、听字训练）。

## 功能一览

| 模块 | 内容 |
| --- | --- |
| 记数字 | 1-100 数字编码表、数字串记忆（5/8/10/12 位）、编码提示、读数练习、圆周率 50 位 |
| 记单词 | 小学 / 初中 / 高中 576 词，看词忆义、看义忆词，每词带音标、释义、记忆提示，未掌握词自动复习 |
| 记古诗词 | 50 首经典古诗，画图记忆法四步，原文 / 译文 / 图解提示，逐句背诵自测 |
| 记短文 | 12 篇经典短文，关键词提取、分段记忆、逐段核对 |
| 记忆方法 | 方法总览、锁链奇像法、对应联想五法、抽象转具象、记忆宫殿、三十六计 |
| 专注力 | 舒尔特方格计时、数数拍手、16 词顺序记忆、听字训练 |
| 统计 | 各模块训练次数、正确率、待复习单词数，本地保存 |
| 关于 | 产品介绍与商业说明 |

## 快速开始

### 网页版（推荐，手机可用）

直接用浏览器打开 `app/index.html` 即可，无需服务器、无需联网。

- **电脑**：双击 `app/index.html`，或运行 `scripts/install.sh` 一键安装到桌面。
- **手机**：把 `app/index.html` 传到手机（微信 / QQ / 数据线 / 网盘），用浏览器打开。
- **部署**：放到任意静态服务器（GitHub Pages、Nginx、内网服务器）后，手机可"添加到主屏幕"作为 PWA 使用，体验接近原生 App。

### 桌面版（Ubuntu）

```bash
cd app
python3 main.py
```

### 重新生成网页版

修改 `app/data.py` 中的数据（词库、古诗、短文、编码），然后：

```bash
cd app && python3 build_web.py
```
