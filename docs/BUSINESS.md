# 变现与商业化方案

本工具定位为**可离线、可私有化、可定制的记忆训练产品**，以下给出可落地的变现路径。
当前版本为免费基础版，所有变现均基于"基础免费 + 增值付费 / 服务收费"的模式。

## 一、免费增值（Freemium）

**基础版免费**（当前全部功能），吸引用户使用、形成口碑与传播；**专业版收费**，增加高价值能力。

建议专业版功能（按需实现，均可通过 `data.py` 与 `build_web.py` 扩展）：

- 更大词库 / 更多古诗与短文（当前 576 词、50 诗、12 短文，可扩充到数千词、上百篇）
- 批量导入自定义词库、课文、记忆内容（教育场景刚需）
- 数据导出与备份（Excel / 文本 / JSON）
- 错题本与艾宾浩斯复习提醒（更智能的复习调度）
- 去除"关于页"中的开源提示，替换为品牌信息
- 云端同步多设备进度（需后端，成本较高，作为高阶功能）

**定价参考**：个人版 19-69 元 / 年；家庭版 99-199 元 / 年。

## 二、内容定制服务

面向学校、培训机构、家长提供**按需定制内容**，按工作量收费：

- 定制校本词库、课文、古诗、短文（按篇 / 按词收费）
- 按客户教材或课程定制记忆提示与串联方案
- 定制品牌界面（Logo、配色、名称）

**定价参考**：定制词库 0.1-0.5 元 / 词；定制短文 20-80 元 / 篇；整校定制按项目报价。

## 三、教育授权

- **机构授权**：学校、培训机构批量授权，按机构 / 按年收费，支持内网私有化部署。
- **教材配套**：作为记忆法教材、课程的配套练习工具，随教材 / 课程销售。

**定价参考**：机构版 999-9999 元 / 年；内网部署按服务器数量与服务期报价。

## 四、私有化部署

面向有数据合规要求的企业、学校、机关，提供**内网部署**：

- 部署到客户内网服务器 / NAS，数据不出内网
- 提供部署文档与技术支持

**定价参考**：部署服务 500-3000 元 / 次；年度维护 20%-30% 部署费。

## 五、开源引流 + 付费增值

- 在 GitHub 开源免费版，积累用户、Star 与口碑；
- 通过免费版引流，转化专业版、定制服务与教育授权。
- 仓库本身即产品页，README 与演示即销售材料。

## 六、配套内容销售

- 将本工具与**记忆法课程、速记教材、训练计划**打包销售；
- 工具提升内容交付体验，内容为工具提供价值背书，互相促进。

## 落地建议（按顺序）

1. 开源免费版，完善文档与演示（当前已完成）；
2. 上线专业版功能（先做词库扩充、批量导入、导出，成本低、需求强）；
3. 提供定制服务报价页，从朋友圈、本地学校、培训机构切入首个客户；
4. 做出 2-3 个案例后，推机构授权与私有化部署；
5. 按需补齐云同步等高阶功能，形成分层定价。

## 注意事项

- 内容版权：古诗、短文按通行版本整理，商用前建议核对教材版权，必要时使用自创内容或获得授权。
- 商标：如做品牌化销售，建议注册自有商标，避免与既有产品冲突。
- 协议：当前为 MIT，允许商用；如需限制"免费商用、付费授权"，可将 LICENSE 调整为自定义许可或双许可。
